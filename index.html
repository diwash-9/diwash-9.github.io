01 — About

A student who ships like a professional.

I'm Devraj, a Computer Science undergraduate from Nepal. I started with C, Python and Java in college, then went deep into modern web — React + TypeScript on the front, FastAPI + PostgreSQL on the back — and into Linux tooling on Arch / Omarchy (Hyprland).

My two biggest builds are Bidhan — a Duolingo-style game for all 308 articles of Nepal's constitution with 1,200+ quiz questions, hearts, streaks and leaderboards — and Matchday — an end-to-end tournament manager with live draws, fixtures, brackets and printable certificates.

Outside code I run a YouTube channel where I teach what I learn, and I maintain three Omarchy community plugins used on real desktops every day.
